# CELL · 生命微观剧场

一套用 Three.js 与**GLSL** 构建的细胞生物学沉浸式演示课件。
六个章节，每章一个独立的三维世界，全部几何体与材质在运行时程序化生成——
没有任何模型文件、贴图文件或后期处理插件。

视觉方向：**深海生物荧光 × 实验室影像仪器**。近黑的深蓝底色上，
结构用冷青色发光，能量用琥珀色，遗传物质用品红——追求电影级的体积感与生命感，
而不是教科书式的彩色解剖图。

---

## 运行

需要一个本地静态服务器（ES modules 不能从 `file://` 加载）：

```bash
cd cell-courseware
node tools/serve.mjs 8127
# 打开 http://127.0.0.1:8127/
```

Windows 上也可以直接双击 `start.cmd`。

**浏览器要求**：支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox / Safari 15+）。
Three.js 已随仓库提供（`vendor/three.module.js`），**离线可用**；
Google Fonts 仅作增强，断网时自动回退到系统字体。

## 技术要点

### 自定义后期处理管线（`src/core/post.js`）

没有使用 `EffectComposer`，而是从零实现了一条 HDR 管线，让调色、景深与体积光
共享同一套色彩流程：

```
场景 ──► HDR RT (RGBA16F + 深度纹理)
          ├─► 体积光   从投影光源做径向散射（quarter res）
          ├─► Bloom    阈值 → 5 级渐进降采样 → 帐篷滤波加性升采样
          ├─► 景深     半分辨率可分离模糊，合成时按 CoC 混合
          └─► 合成     色差 · 桶形畸变 · 景深混合 · Bloom · 体积光
                       · ACES · lift/gain · 饱和/对比 · 暗角 · 胶片颗粒 · sRGB
```

### 粒子系统（`src/core/particles.js`）

两套引擎，按用途分工：

* **`FieldPoints`** —— 完全由顶点着色器解析驱动（curl 噪声流场 + 呼吸 + 环绕）。
  每帧 CPU 成本恒为一个 uniform，因此可以放心用上万颗粒。
* **`ParticleSystem`** —— CPU 池化模拟，带生命周期，用交换压缩保持绘制区间紧凑。
  用于事件驱动的爆发（ATP 释放、囊泡融合、离子跨膜）。

### 程序化生物结构（`src/core/builders.js`）

所有细胞器都是代码生成的：

* `makeTube()` —— 沿曲线的可变半径管道，附加 `aFlow` 属性供流动线材质使用
  （染色质、染色体、微管、纺锤丝都基于它）
* `makeNucleus()` —— 双层核膜 + 斐波那契球分布的核孔 + 缠绕的染色质 + 核仁
* `makeMitochondrion()` —— 椭球外膜 + 噪声褶皱的嵴「搁板」+ 实例化的 ATP 合成酶转子
* `makeMembraneField()` —— 六方点阵上的磷脂双分子层，两层叶片共享同一个噪声场起伏，
  因而整片膜像液体一样一起波动
* `makeChromosome()` —— 两条在着丝粒交叉的染色单体，构成可分离的 X 形

### 着色器约定

* **预乘 alpha**：所有自发光材质写 `vec4(col * a, a)`，因此必须用
  `(One, One)` 混合。three 的 `AdditiveBlending` 是 `(SrcAlpha, One)`，
  会把 alpha 乘第二次、把衰减平方掉——低不透明度的壳会直接塌成黑色。
  见 `materials.js` 中的 `ADDITIVE`。
* **距离雾**：每种材质都按相机距离做指数雾，结构背面沉入黑暗，画面才有纵深，
  否则加性混合会糊成一片奶白色的雾。
* 材质输出线性 HDR 值；sRGB 转换只在最后的合成 pass 里做一次。

### 相机（`src/core/camera.js`）

Catmull-Rom 样条驱动的运镜，叠加手持噪声、鼠标视差与撞击抖动。
用户的旋转/推拉以**当前注视点**为球心施加偏移，而不是世界原点——
否则在偏心构图的章节里镜头会甩飞。

## 开发工具

| 命令 | 用途 |
|------|------|
| `node tools/serve.mjs 8127` | 启动静态预览服务器 |
| `node tools/check.mjs` | 对所有 ES 模块做语法检查 |
| `node tools/build-check.mjs` | 逐个构建六个章节，报告失败与空场景 |
| `node tools/utf8-check.mjs <file> [--fix]` | 检查/修复 UTF-8 损坏 |
| `node tools/shot.mjs --url … --out …` | 无头 Chrome 截图 + 控制台错误捕获 |
| `node tools/playback.mjs 40` | 依次走完全部章节，报告错误与帧率 |

调试用的 URL 参数：`?auto=1` 跳过入场门，`&scene=3` 直达章节，
`&t=12` 跳到该章第 12 秒，`&pause=1` 冻结时间轴。

运行时还暴露了 `window.__cell`（`goto` / `seek` / `pause` / `info`）
与 `window.__app`，便于自动化验证。

## 性能

* 分辨率按帧率自适应缩放（`_autoScale`，0.62×–1.0×）
* 全部着色器在入场前预编译，章节切换不会卡顿
* 章节惰性构建并**保留**：来回跳转是瞬时的，不会重建
* 桌面独显上以 1080p 满帧为目标；集成显卡会自动降分辨率

## 内容说明

文案中的数值取自通行的细胞生物学教材（细胞直径约 20 µm、
磷脂双分子层厚约 5 nm、ATP 合成酶转速约 130 r/s 等）。
三维结构为**示意性表达**——为了视觉可读性，比例、数量与排布均经过艺术夸张，
不应用于定量判读。
